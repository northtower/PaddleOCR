## 🚀 快速开始

### 1️⃣ 环境检查（首次使用）

```powershell
cd C:\codeBase\ocr\PaddleOCR\ppstructure
conda activate paddleocr310
.\check_environment.ps1
```

如果提示缺少依赖：
```powershell
.\install_dependencies.ps1
```

### 2️⃣ 选择运行模式

#### 🔥 单图快速识别（最推荐）
```powershell
.\pure_ocr_fast.ps1 "图片路径.jpg"
```
**耗时：3秒 | 实际推理：0.6秒 ✨**

#### 📦 批量处理（最高效）
```powershell
.\batch_ocr.ps1 "图片文件夹"
```
**首张：7秒 | 后续：1秒/张 ✨✨✨**

#### 📋 完整功能
```powershell
.\quick_run.ps1 "图片路径.jpg"
```
**耗时：10秒 | 功能：完整（布局+表格+OCR）**

## 🎓 技术要点

### 为什么快？
1. **纯OCR模式**：跳过布局和表格分析（节省5秒）
2. **批量处理**：模型只加载一次（节省6秒×N）
3. **GPU加速**：充分利用CUDA（检测+识别<1秒）

### 核心环节耗时
根据实测数据：
- 模型初始化：6-7秒（仅首次）
- 文本检测：0.1-0.2秒
- 文本识别：0.3-0.6秒
- 布局分析：1-2秒（可选）
- 后处理：0.3-0.5秒

### 优化建议
1. 单图识别 → 用 `pure_ocr_fast.ps1`
2. 批量处理 → 用 `batch_ocr.ps1`
3. 生产环境 → 部署为服务（模型常驻）
