## ⚠️ 核心问题

### 兼容性问题

```
❌ ValueError: Not find predictor_id 1 and pass_name memory_optimize_pass
```

**原因：**
- PP-OCRv5 使用 PaddleX 格式（`.yml`）
- 当前代码期望传统格式（`.pdmodel`）
- 需要代码适配或模型转换

**解决时间：1-2个月**

## 🚀 升级路径（如需升级）

### 方案1：使用 PaddleX SDK（推荐）

```bash
# 安装
pip install paddlex

# 使用
from paddlex import create_pipeline
ocr = create_pipeline("OCR", det_model="PP-OCRv5_server_det")
result = ocr.predict("image.jpg")
```

**优点：** 简单，官方支持  
**缺点：** 需要重写部分代码  
**时间：** 2-3周

### 方案2：转换模型格式

```bash
# 将 PaddleX 格式转换为传统格式
python convert_model.py --input=v5_model --output=converted_model
```

**优点：** 无需修改代码  
**缺点：** 转换复杂，可能失败  
**时间：** 1-2周（如果成功）

### 方案3：升级推理代码

修改 `tools/infer/utility.py` 支持 `.yml` 格式。

**优点：** 长期方案，一劳永逸  
**缺点：** 改动大，测试工作量大  
**时间：** 3-4周
